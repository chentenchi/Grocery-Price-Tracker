\# Grocery Price Tracker



A data analytics project that tracks daily Kroger grocery prices and compares them with historical U.S. Bureau of Labor Statistics food-price benchmarks.



\## Project Overview



This project combines automated API data collection, Python ETL, SQLite, and Tableau to analyze grocery price trends.



The pipeline collects daily prices for a basket of 22 grocery products from the Kroger API and compares 16 matching categories against historical BLS average food prices from 2017 onward.



\## Data Pipeline



Kroger API → Python → SQLite / CSV → Tableau



BLS API → Python → SQLite / CSV → Tableau



\## Features



\- Daily automated Kroger price collection

\- 22 tracked grocery products

\- Regular and promotional price tracking

\- Standardized price-per-unit calculations

\- Historical BLS food-price data

\- Kroger vs. U.S. price comparisons

\- Current 22-item grocery basket cost

\- Current sale-item tracking

\- Interactive Tableau dashboard
